# MAXIN Centro Odontológico — Dr. Raúl Sucari Cruz

Sitio web del consultorio odontológico **MAXIN**, del Dr. Raúl Sucari Cruz, en
Juliaca (Puno, Perú).

🔗 **Ver la página:** https://drogueriasuker-glitch.github.io/Raul-Sucari/

## Qué incluye

- Presentación del doctor y su trayectoria
- Tratamientos: cirugía oral, muelas del juicio, implantes, odontología general,
  estética y rehabilitación oral
- Ubicación del consultorio con mapa de Google e indicaciones para llegar
- Contacto directo por WhatsApp

## Cómo está hecho

HTML, CSS y JavaScript puro. Sin frameworks, sin dependencias y sin compilación:
se abre `index.html` y funciona. Para publicarlo basta con subir los archivos por FTP.

```
index.html        página completa
css/styles.css    estilos e identidad visual
js/main.js        menú, animaciones y mapa
assets/           logo, fotos y logos de redes sociales
```

La identidad visual sale del logo: navy `#02164A` y dorado `#FFC401`, con el anillo
del logo animado en 3D en la portada.
